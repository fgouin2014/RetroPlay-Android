========================================
FBNeo ROM Information
========================================

FBNeo (FinalBurn Neo) is a multi-arcade system emulator supporting:
- Neo Geo
- CPS1 (Capcom Play System 1)
- CPS2 (Capcom Play System 2)
- CPS3 (Capcom Play System 3)
- And many other arcade systems

LEGAL ROMS FOR TESTING:
-----------------------

1. Gridlee (gridlee.zip)
   - Same ROM as MAME, also compatible with FBNeo
   - Public domain arcade game
   - Download: MAME.org or FBNeo ROM set

2. FBNeo Homebrew Games
   - Check FBNeo forums for homebrew releases
   - Some Neo Geo homebrew games are freely available

BIOS REQUIREMENTS:
------------------
Neo Geo games require: neogeo.zip (BIOS)
- Place in: /storage/emulated/0/GameLibrary-Data/data/bios/

ROM SET COMPATIBILITY:
----------------------
FBNeo uses the LATEST ROM sets, which may differ from MAME sets.
- Always use ROMs specifically for FBNeo
- ROM sets are version-specific (e.g., v1.0.0.03)
- Check https://github.com/finalburnneo/FBNeo for compatibility

INSTALLATION:
-------------
1. Download a compatible ROM
2. Copy to: /storage/emulated/0/GameLibrary-Data/fbneo/
3. Ensure neogeo.zip BIOS is in data/bios/ (for Neo Geo games)
4. Update gamelist.json
5. Launch RetroPlay

NOTES:
------
- Most arcade ROMs are copyrighted
- Only use legally obtained ROMs
- FBNeo offers better performance than MAME for supported systems
- Excellent for fighting games (CPS2)
