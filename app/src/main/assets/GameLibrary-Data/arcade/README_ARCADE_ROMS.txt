========================================
Legal Arcade ROMs for Testing
========================================

The arcade directory requires ROM files compatible with MAME cores.
Below are LEGALLY available ROMs you can download:

FREE/LEGAL ARCADE ROMS:
-----------------------

1. Gridlee (gridlee.zip)
   - Developer: Videa (released to public domain)
   - Year: 1983
   - Size: ~100 KB
   - Download: Included in official MAME distribution
   - URL: https://www.mamedev.org/roms/
   - Compatible cores: MAME2003, MAME2003-Plus, MAME2010, FBNeo

2. Robby Roto (robby.zip)
   - Developer: Bally Midway (public domain)
   - Year: 1981
   - Size: ~50 KB
   - Download: Included in official MAME distribution
   - Compatible cores: MAME2003, MAME2003-Plus, MAME2010

3. Free MAME ROMs Collection
   - URL: https://www.mamedev.org/roms/
   - Note: Only download ROMs explicitly marked as "free" or "public domain"

INSTALLATION:
-------------
1. Download a legal ROM (e.g., gridlee.zip)
2. Copy the .zip file to this directory:
   /storage/emulated/0/GameLibrary-Data/arcade/
3. Update gamelist.json to reference the ROM
4. Launch RetroPlay and select the game

IMPORTANT NOTES:
----------------
- Most arcade ROMs are copyrighted and NOT legal to download
- Only use ROMs from games explicitly released as freeware/public domain
- MAME.org provides a list of legally redistributable ROMs
- When in doubt, check the ROM's legal status before downloading

CORES COMPARISON:
-----------------
- MAME2003: ROM set 0.78 (2003)
- MAME2003-Plus: ROM set 0.78+ (enhanced)
- MAME2010: ROM set 0.139 (2010)
- FBNeo: Latest ROM sets (Neo Geo, CPS1/2/3)

Different cores require different ROM versions!
