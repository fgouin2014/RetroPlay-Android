# Outil PC pour générer les gamelist.json

Cet outil génère les `gamelist.json` sur votre PC avec la **même logique** que l'app Android.

## Prérequis

- Python 3.6 ou supérieur
- Aucune dépendance externe (utilise uniquement les bibliothèques standard)

## Usage

### Générer tous les gamelist.json

```bash
python generate_gamelist_pc.py <chemin_vers_GameLibrary-Data>
```

Exemple:
```bash
python generate_gamelist_pc.py C:/GameLibrary-Data
python generate_gamelist_pc.py D:/RetroPlay/GameLibrary-Data
```

### Générer pour une console spécifique

```bash
python generate_gamelist_pc.py <chemin_vers_GameLibrary-Data> <console_id>
```

Exemple:
```bash
python generate_gamelist_pc.py C:/GameLibrary-Data nes
python generate_gamelist_pc.py C:/GameLibrary-Data psx
```

## Fonctionnalités

- **Même logique que l'app Android**: Utilise les mêmes extensions, normalisation de console, et calcul de hash
- **Calcul de hash complet**: CRC32, MD5, SHA1 (identique à `HashCalculator.kt`)
- **Support archives ZIP**: Extrait et calcule les hashes depuis les ROMs dans les ZIP
- **Header iNES**: Skip automatique du header 16 bytes pour les ROMs NES
- **Format identique**: Génère des `gamelist.json` avec la même structure que l'app Android
- **Sauvegarde automatique**: Crée une sauvegarde de l'ancien `gamelist.json` si il existe

## Format généré

Le format est identique à celui généré par l'app Android:

```json
{
  "version": "1.0",
  "console": "nes",
  "games": [
    {
      "id": "1",
      "name": "Super Mario Bros",
      "path": "./Super Mario Bros.nes",
      "desc": null,
      "image": "./media/box2d/Super Mario Bros.png",
      "releasedate": null,
      "developer": null,
      "publisher": null,
      "genre": null,
      "players": null,
      "hash": "a1b2c3d4e5f6...",
      "rating": null
    }
  ],
  "metadata": {
    "generatedAt": 1234567890000,
    "sourceDirectories": ["C:/GameLibrary-Data/nes"],
    "autoGenerated": true,
    "totalGames": 1,
    "console": "nes"
  }
}
```

## Workflow recommandé

1. **Générer les gamelist.json sur PC**:
   ```bash
   python generate_gamelist_pc.py C:/GameLibrary-Data
   ```

2. **Copier les gamelist.json sur le device**:
   ```bash
   adb push C:/GameLibrary-Data/nes/gamelist.json /storage/emulated/0/GameLibrary-Data/nes/
   adb push C:/GameLibrary-Data/snes/gamelist.json /storage/emulated/0/GameLibrary-Data/snes/
   # ... etc
   ```

3. **L'app Android détectera automatiquement les nouvelles ROMs** au démarrage et les ajoutera au `gamelist.json` existant (sans écraser les métadonnées)

## Notes

- Les répertoires système sont ignorés: `data`, `emulatorjs`, `vmnes`, `playlists`, `saves`, `states`, `cheats`, `media`, `overlays`, `cores`, `bios`, `.cache`
- Le scan est récursif (max 2 niveaux de profondeur)
- Les hashes sont calculés de la même manière que dans l'app Android (même algorithme, même buffer size, même gestion des headers)
