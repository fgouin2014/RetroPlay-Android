# Explication : WebServer et chargement des gamelists

## 🔍 CHARGEMENT DE LA GAMELIST

### Méthode 1 : Accès direct au fichier (PRINCIPALE)

**Dans `GameListActivity.loadGames()` (ligne 680-739) :**

```java
// 1. Lire directement depuis le système de fichiers
String gamelistPath = "/storage/emulated/0/GameLibrary-Data/" + realConsoleDirectory + "/gamelist.json";
File gamelistFile = new File(gamelistPath);

if (gamelistFile.exists()) {
    // ✅ Fichier existe → Lecture directe (RAPIDE)
    FileInputStream fis = new FileInputStream(gamelistFile);
    byte[] buffer = new byte[(int) gamelistFile.length()];
    fis.read(buffer);
    String json = new String(buffer, StandardCharsets.UTF_8);
    parseAndDisplayGames(json, realConsoleDirectory);
}
```

**Avantages :**
- ✅ **Rapide** : Accès direct au fichier, pas de réseau
- ✅ **Pas de dépendance** : Fonctionne même si le WebServer n'est pas démarré
- ✅ **Simple** : Lecture fichier standard Java

### Méthode 2 : Via WebServer (FALLBACK - Auto-génération)

**Dans `GameListActivity.loadGames()` (ligne 684-717) :**

```java
if (!gamelistFile.exists()) {
    // ❌ Fichier n'existe pas → Tentative auto-génération via WebServer
    URL autoScanUrl = new URL("http://localhost:7777/gamedata/" + realConsoleDirectory + "/gamelist.json");
    HttpURLConnection autoConn = (HttpURLConnection) autoScanUrl.openConnection();
    
    if (autoConn.getResponseCode() == 200) {
        // ✅ WebServer a généré automatiquement le gamelist.json
        // Le serveur scanne les ROMs et génère le JSON à la volée
        BufferedReader reader = new BufferedReader(new InputStreamReader(autoConn.getInputStream()));
        String json = reader.readLine(); // Lire le JSON généré
        parseAndDisplayGames(json, realConsoleDirectory);
    }
}
```

## 🎯 POPULATION DES CONSOLES

### Via WebServer (OBLIGATOIRE)

**Dans `GameListActivity.loadAvailableConsoles()` (ligne 1693-1708) :**

```java
// Appeler l'API REST du WebServer
URL url = new URL("http://localhost:7777/gamelibrary/api/consoles");
HttpURLConnection conn = (HttpURLConnection) url.openConnection();
conn.setRequestMethod("GET");

if (conn.getResponseCode() == 200) {
    // Lire la réponse JSON
    BufferedReader reader = new BufferedReader(new InputStreamReader(conn.getInputStream()));
    StringBuilder response = new StringBuilder();
    String line;
    while ((line = reader.readLine()) != null) {
        response.append(line);
    }
    
    // Parser le JSON
    JSONObject jsonObj = new JSONObject(response.toString());
    JSONArray consolesArray = jsonObj.getJSONArray("consoles");
    
    // Créer les objets ConsoleInfo
    for (int i = 0; i < consolesArray.length(); i++) {
        JSONObject consoleObj = consolesArray.getJSONObject(i);
        if (consoleObj.getBoolean("enabled")) {
            tempConsoles.add(new ConsoleInfo(
                consoleObj.getString("id"),
                consoleObj.getString("name"),
                consoleObj.getString("fullName"),
                consoleObj.getString("directory")
            ));
        }
    }
}
```

**Dans `WebServer.serveConsolesAPI()` :**

Le WebServer scanne les répertoires dans `/storage/emulated/0/GameLibrary-Data/` et retourne la liste des consoles disponibles au format JSON.

**Pourquoi via WebServer ?**
- ✅ **Dynamique** : Détecte automatiquement les consoles disponibles
- ✅ **Standardisé** : Format JSON uniforme
- ✅ **Centralisé** : Une seule source de vérité

## 🔄 FLUX COMPLET

### Chargement des jeux (GameListActivity)

```
1. Vérifier si gamelist.json existe directement
   ├─ ✅ OUI → Lire directement (RAPIDE)
   └─ ❌ NON → Appeler WebServer pour auto-génération
       ├─ WebServer scanne les ROMs
       ├─ Génère le JSON
       └─ Retourne le JSON via HTTP
```

### Population des consoles (GameListActivity)

```
1. Appeler API WebServer : GET /gamelibrary/api/consoles
2. WebServer scanne /storage/emulated/0/GameLibrary-Data/
3. Retourne JSON avec toutes les consoles
4. GameListActivity parse le JSON et crée ConsoleInfo[]
```

## 💡 EN RÉSUMÉ

**Pour la gamelist :**
- **Normalement** : Accès direct au fichier (rapide, pas de WebServer nécessaire)
- **Si fichier manquant** : WebServer auto-génère (lent, nécessite WebServer)

**Pour la population des consoles :**
- **Toujours** : Via WebServer API (nécessite WebServer démarré)

**Impact sur les performances :**
- Si `gamelist.json` existe : Le WebServer n'est **pas utilisé** pour charger la gamelist
- Si `gamelist.json` n'existe pas : Le WebServer **génère** la gamelist (plus lent)
- Pour les consoles : Le WebServer est **toujours nécessaire** pour lister les consoles
