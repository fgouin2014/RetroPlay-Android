## 📊 DIFFÉRENCE DES FORMATS

### Format Actuel (Notre App)
**Fichier:** `gamelist.json` (JSON)

```json
{
  "version": "1.0",
  "console": "nes",
  "games": [
    {
      "id": "1",
      "name": "Super Mario Bros",
      "path": "./Super Mario Bros.nes",
      "description": "The classic platformer...",
      "releaseDate": "19850913",
      "genre": "Platform",
      "players": "1-2",
      "crc32": "a1b2c3d4",
      "size": 40960
    }
  ],
  "metadata": {
    "generatedAt": 1234567890,
    "autoGenerated": true
  }
}
```

### Format RetroPie/EmulationStation
**Fichier:** `gamelist.xml` (XML)

```xml
<?xml version="1.0"?>
<gameList>
    <game>
        <path>./Super Mario Bros.nes</path>
        <name>Super Mario Bros</name>
        <desc>The classic platformer...</desc>
        <image>./media/box2d/Super Mario Bros.png</image>
        <thumbnail>./media/box2d/Super Mario Bros.png</thumbnail>
        <video>./media/video/Super Mario Bros.mp4</video>
        <marquee>./media/marquee/Super Mario Bros.png</marquee>
        <releasedate>19850913T000000</releasedate>
        <developer>Nintendo</developer>
        <publisher>Nintendo</publisher>
        <genre>Platform</genre>
        <players>1-2</players>
        <rating>0.85</rating>
        <favorite>false</favorite>
        <playcount>0</playcount>
        <lastplayed></lastplayed>
    </game>
</gameList>
```

## 🔍 ANALYSE DE COMPATIBILITÉ

### ✅ Points Communs

| Champ | Notre Format | RetroPie/ES | Compatible |
|-------|-------------|-------------|------------|
| `name` | ✅ `name` | ✅ `<name>` | ✅ Oui |
| `path` | ✅ `path` | ✅ `<path>` | ✅ Oui |
| `description` | ✅ `description` | ✅ `<desc>` | ⚠️ Nom différent |
| `releaseDate` | ✅ `releaseDate` | ✅ `<releasedate>` | ⚠️ Format différent |
| `genre` | ✅ `genre` | ✅ `<genre>` | ✅ Oui |
| `players` | ✅ `players` | ✅ `<players>` | ✅ Oui |
| `image` | ✅ `image` | ✅ `<image>` | ✅ Oui |
| `thumbnail` | ✅ `thumbnail` | ✅ `<thumbnail>` | ✅ Oui |

### ❌ Champs Uniques à RetroPie/ES

- `<video>` : Vidéo de gameplay
- `<marquee>` : Marquee/logo du jeu
- `<developer>` : Développeur
- `<publisher>` : Éditeur
- `<rating>` : Note (0.0-1.0)
- `<favorite>` : Favori (booléen)
- `<playcount>` : Nombre de parties
- `<lastplayed>` : Dernière partie jouée

### ❌ Champs Uniques à Notre Format

- `id` : ID séquentiel
- `crc32` : Checksum CRC32
- `size` : Taille du fichier
- `serial` : Numéro de série (PSX)
- `md5` / `sha1` : Hashes
- `corePath` / `coreName` : Configuration core
- `metadata` : Métadonnées de génération

## 🎯 STRATÉGIE DE COMPATIBILITÉ

### Option 1: Support Dual Format (Recommandé)

**Générer les deux formats :**
- `gamelist.json` : Pour notre app (format complet avec métadonnées)
- `gamelist.xml` : Pour RetroPie/ES (format standard)

**Avantages :**
- ✅ Compatibilité maximale
- ✅ Partage facile avec RetroPie/ES
- ✅ Format JSON reste pour notre app

**Inconvénients :**
- ⚠️ Deux fichiers à maintenir
- ⚠️ Synchronisation nécessaire

### Option 2: Conversion à la Demande

**Générer seulement JSON, convertir en XML si nécessaire**

**Avantages :**
- ✅ Un seul format source
- ✅ Pas de duplication

**Inconvénients :**
- ⚠️ Conversion nécessaire pour partage
- ⚠️ Perte de données (champs uniques)

### Option 3: Format Unifié (JSON + Compatibilité)

**Générer JSON avec champs compatibles RetroPie/ES**

**Avantages :**
- ✅ Un seul format
- ✅ Compatible avec les deux

**Inconvénients :**
- ⚠️ Format hybride peut être confus
- ⚠️ Outils RetroPie/ES ne lisent pas JSON

## 💡 RECOMMANDATION : Option 1 (Dual Format)

### Implémentation Proposée

1. **Générer `gamelist.json`** (format actuel, complet)
2. **Générer `gamelist.xml`** (format RetroPie/ES, compatible)
3. **Synchronisation automatique** lors de la génération

### Fonctionnalités

```kotlin
// Dans GamelistManager.kt

/**
 * Sauvegarde un gamelist dans les deux formats
 */
fun saveGamelistDualFormat(gamelist: Gamelist, consoleDir: File): Boolean {
    // 1. Sauvegarder JSON (format actuel)
    val jsonSuccess = saveGamelist(gamelist, consoleDir)
    
    // 2. Sauvegarder XML (format RetroPie/ES)
    val xmlSuccess = saveGamelistXml(gamelist, consoleDir)
    
    return jsonSuccess && xmlSuccess
}

/**
 * Sauvegarde un gamelist au format XML RetroPie/EmulationStation
 */
fun saveGamelistXml(gamelist: Gamelist, consoleDir: File): Boolean {
    try {
        val xmlFile = File(consoleDir, "gamelist.xml")
        
        val xml = StringBuilder()
        xml.append("<?xml version=\"1.0\"?>\n")
        xml.append("<gameList>\n")
        
        gamelist.games.forEach { game ->
            xml.append("    <game>\n")
            xml.append("        <path>${escapeXml(game.path)}</path>\n")
            xml.append("        <name>${escapeXml(game.name)}</name>\n")
            
            // Description (desc dans XML, description dans JSON)
            if (game.description != null && game.description.isNotEmpty()) {
                xml.append("        <desc>${escapeXml(game.description)}</desc>\n")
            }
            
            // Images
            val baseName = game.name
            xml.append("        <image>./media/box2d/${escapeXml(baseName)}.png</image>\n")
            xml.append("        <thumbnail>./media/box2d/${escapeXml(baseName)}.png</thumbnail>\n")
            
            // Release date (format RetroPie: YYYYMMDDT000000)
            if (game.releaseDate != null && game.releaseDate.isNotEmpty()) {
                val releaseDate = formatReleaseDateForXml(game.releaseDate)
                xml.append("        <releasedate>${releaseDate}</releasedate>\n")
            }
            
            // Genre
            if (game.genre != null && game.genre.isNotEmpty()) {
                xml.append("        <genre>${escapeXml(game.genre)}</genre>\n")
            }
            
            // Players
            if (game.players != null && game.players.isNotEmpty()) {
                xml.append("        <players>${escapeXml(game.players)}</players>\n")
            }
            
            // Champs optionnels RetroPie/ES
            xml.append("        <favorite>false</favorite>\n")
            xml.append("        <playcount>0</playcount>\n")
            xml.append("        <lastplayed></lastplayed>\n")
            
            xml.append("    </game>\n")
        }
        
        xml.append("</gameList>\n")
        
        xmlFile.writeText(xml.toString())
        Log.i(TAG, "Saved gamelist.xml for ${consoleDir.name}: ${gamelist.games.size} games")
        return true
        
    } catch (e: Exception) {
        Log.e(TAG, "Error saving gamelist.xml: ${e.message}", e)
        return false
    }
}

/**
 * Formate une date pour le format RetroPie/ES (YYYYMMDDT000000)
 */
private fun formatReleaseDateForXml(dateStr: String): String {
    // Format attendu: YYYYMMDD ou YYYY-MM-DD
    // Convertir en YYYYMMDDT000000
    return when {
        dateStr.matches(Regex("\\d{8}")) -> "${dateStr}T000000"
        dateStr.matches(Regex("\\d{4}-\\d{2}-\\d{2}")) -> {
            dateStr.replace("-", "") + "T000000"
        }
        else -> dateStr
    }
}

/**
 * Échappe les caractères XML spéciaux
 */
private fun escapeXml(text: String): String {
    return text
        .replace("&", "&amp;")
        .replace("<", "&lt;")
        .replace(">", "&gt;")
        .replace("\"", "&quot;")
        .replace("'", "&apos;")
}
```
