## ✅ CHANGEMENTS IMPLÉMENTÉS

### 1. **Format Standardisé (camelCase)**

**Avant (Legacy):**
```json
{
  "desc": "...",
  "releasedate": "..."
}
```

**Après (Nouveau Format Standard):**
```json
{
  "description": "...",
  "releaseDate": "..."
}
```

**Impact:**
- ✅ +7 bytes par jeu (négligeable)
- ✅ Format cohérent et lisible
- ✅ Compatible avec standards modernes

### 2. **Support Migration Automatique**

**Parsing dans `parseGameEntry()`:**
```kotlin
// Support des deux formats avec priorité au nouveau
val description = obj.optString("description", null) 
    ?: obj.optString("desc", null)  // Fallback legacy
val releaseDate = obj.optString("releaseDate", null) 
    ?: obj.optString("releasedate", null)  // Fallback legacy
```

**Parsing dans `GameListActivity.parseAndDisplayGames()`:**
```java
// PRIORITÉ au nouveau format
String desc = obj.optString("description", "");
if (desc.isEmpty()) {
    desc = obj.optString("desc", "");  // Fallback legacy
}
String releaseDate = obj.optString("releaseDate", "");
if (releaseDate.isEmpty()) {
    releaseDate = obj.optString("releasedate", "");  // Fallback legacy
}
```

### 3. **PSX Serial Numbers**

**Nouveau:** `PSXSerialExtractor.kt`
- Extrait les numéros de série PSX depuis les headers (64KB)
- Format: `SLUS-01234`, `SLES-00567`, etc.
- Support de tous les préfixes officiels (17 préfixes)

**Intégration dans `createGameEntryFromFile()`:**
```kotlin
// Pour PSX, utiliser serial au lieu de CRC32
val serial = if (consoleId == "psx") {
    PSXSerialExtractor.extractSerial(file)
} else {
    null
}

// CRC32 seulement si pas PSX
val crc32 = if (consoleId != "psx") {
    calculateCRC32(file)
} else {
    null  // Pas de CRC32 pour PSX, on utilise serial
}
```

### 4. **Génération Cohérente**

**Tous les endroits génèrent maintenant le nouveau format:**
- ✅ `gameToJson()` : Format standard (description, releaseDate)
- ✅ `generateGamelistJsonString()` : Format standard
- ✅ `saveGamelist()` : Format standard

## 🎯 CAS SPÉCIAUX

### PSX - Numéros de Série

**Pour PSX uniquement:**
- ✅ Utilise `serial` (SLUS-01234) au lieu de `crc32`
- ✅ Extraction depuis les 64 premiers KB du fichier
- ✅ Support de 17 préfixes officiels
- ✅ Format standardisé: `PREFIX-NUMBER` ou `PREFIX-NUMBER.SUBNUMBER`

**Exemples:**
- `SLUS-01234` (USA)
- `SLES-00567` (Europe)
- `SLPS-01234` (Japon)
- `SCUS-94627` (USA, Sony Computer Entertainment)

### Autres Consoles

**Pour toutes les autres consoles:**
- ✅ Utilise `crc32` pour identification
- ✅ `serial` reste `null`
- ✅ Calcul CRC32 optionnel (peut être désactivé pour performance)
